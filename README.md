# DecodeLabs-Task-03 Commercial Office Space Layout
## Description
This project presents a multi-storey commericial office building layout designed using AutoCAD.

## Features Implemented
- Multi-floor office layout (Ground Floor, 1st Floor, 2nd Floor, and 3rd Floor)
- Dynamic Block implementation for furniture elements(Dining table)
- External Reference (XREF) implementation
- Bill of Materials (BOM) generated using Data Extraction
- Organized furniture scheduling and block management

## Files Included
- Project_03_Office_Layout.dwg (Main drawing)
- Office_shell.dwg (XREF reference drawing)

## Software Used
- Autodesk AutoCAD 2022
